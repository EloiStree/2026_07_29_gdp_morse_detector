# 2026_07_29_gdp_morse_detector

> **A Morse Detector example with one-, two-, and three-button input for learning Morse code and serving as a WebGL interface.**

WebGL applications cannot easily use UDP or WebSocket communication in every environment, but they can always receive user input.

The same principle applies to moddable games such as *World of Warcraft*. Instead of sending data directly through a network connection, information can be encoded visually—for example, as colors displayed on the screen—and then decoded externally by simulating keyboard or gamepad input.

To support this workflow, we need a Morse Detector implemented in Godot. It should decode Morse input from one, two, or three buttons and provide a simple bridge between external tools and WebGL or other input-only environments.
